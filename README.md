# Death Zone Visualizer

[![MelonLoader/BepInEx](https://img.shields.io/badge/Platform-MelonLoader%20%2F%20BepInEx-blue)](https://github.com/LavaGang/MelonLoader)
[![Version](https://img.shields.io/badge/Version-1.4.0-brightgreen)]()

**Death Zone Visualizer** is a powerful utility mod designed to help players identify, analyze, and visualize death zones within the game. Whether you are a speedrunner, a mapper, or just curious about level boundaries, this tool provides real-time rendering of death zones with a fully customizable interface.

## 🚀 Features

*   **Real-time Visualization**: Instantly render and toggle death zones in the game world.
*   **X-Ray Mode**: View zones through walls and terrain.
*   **Wireframe Mode**: Simplified geometry rendering for better visibility.
*   **Transparency Control**: Adjust the opacity of the zones to suit your preference.
*   **Dynamic Keybinds**: Remap menu and toggle keys directly from the in-game GUI.
*   **Lightweight**: Minimal performance impact.

## 🛠️ Installation

1.  Ensure you have **MelonLoader** or **BepInEx** installed for your game.
2.  Download the latest `.dll` release from the [Releases page](https://github.com/w3ntr/RunPro-DeathZoneVisualizer/releases)
3.  Place the downloaded `.dll` file into your game's `Mods` folder.
4.  Launch the game. The mod will load automatically.

## 🎮 Usage & Controls

You can open the settings menu in-game to configure the visualizer.

| Function | Default Key | Description |
| :--- | :--- | :--- |
| **Toggle Visuals** | `F2` | Quickly turn death zone rendering ON/OFF. |
| **Open Menu** | `F4` | Open the configuration settings window. |

*Note: All keybinds can be changed via the in-game GUI.*

## ⚙️ Settings GUI
The in-game menu allows you to modify the following on the fly:
*   **Visuals Toggle**: Simple ON/OFF switch.
*   **X-Ray**: Toggle visibility through obstacles.
*   **Wireframe**: Render only the edges of the zones.
*   **Transparency Slider**: Adjust how "ghostly" the zones appear (0% to 100%).
